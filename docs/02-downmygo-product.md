# downmygo：产品定义与重构方案

> 品牌：**downmygo**
> 一句话：**Downloads, on the go.** / **下载，即刻启程。**
> 框架：Go + [MyGo](https://github.com/egoist/mygo) 原生 UI（无 WebView、GPU 绘制、单二进制）
> 平台：Windows 10/11、macOS（Apple Silicon / Intel）、Linux（X11 / Wayland）
> 许可：MIT

---

## 1. 品牌

### 1.1 名字

`downmygo` = **down**load + **my** + **go**。

- 读作 “down-my-go”，三个音节，中文可称“当买购”或直接叫 downmygo。
- 含义：**我的下载，随走随用**；也暗示“下载完就走”，轻快、不拖泥带水。
- 域名/包名：`downmygo.app`、`app.downmygo.desktop`、`downmygo://`。
- 不在名称、图标、文案中出现 IDM 或任何第三方下载器的商标。

### 1.2 标志

- 圆角方块（squircle），135° 渐变：`#4A78FF → #0FA79A`，左上高光、右下压暗。
- 中央白色下载箭头，落在一根进度条上：箭头说“在下载”，进度条说“下了多少”。进度条左侧实心、右侧半透明，读作进度。
- 几何用有符号距离场画（`internal/app/icon.go`），任意尺寸都平滑；托盘是同一几何的单色模板图，系统自动反色。
- 图标源文件是 Icon Composer 文档 `resources/downmygo.icon`（渐变填充 + 标记图层）；`go run ./tools/makeicon` 画图层、调 `ictool` 导出 PNG，再按 macOS 图标网格留边（1024 画布、824 图形）。
- 窗口里的标记（`ui.Mark`）与图标同一套几何，工具栏、空状态、关于窗口一致。

### 1.3 语气

- 平静、直接、可执行。
- 错误文案说“发生了什么 + 下一步”，不堆技术术语。
- 不卖焦虑、不写“极速”“秒杀”“永久免费”这类夸张词。
- 中文文案短句为主，避免翻译腔。

示例：

| 场景 | 文案 |
|---|---|
| 空列表 | 还没有下载。粘贴一个链接，或让 downmygo 从浏览器接管。 |
| 服务器拒绝 | 服务器拒绝了访问（403），这个文件可能需要登录。 |
| 限速到量 | 已达到本时段的流量上限，稍后会自动继续。 |
| 完成 | 下载完成 · 文件名 |

## 2. 定位

### 2.1 一句话定位

> **一个轻、快、漂亮的跨平台下载管理器：多连接加速、断点续传、队列与定时、浏览器接管，原生界面，单文件安装，免费无广告。**

### 2.2 与 MDM 的差异

| 维度 | MDM | downmygo |
|---|---|---|
| 技术 | Rust + egui 自绘 | Go + MyGo 原生 UI |
| 交付 | 安装器/压缩包/多包 | 单二进制 + 系统安装包 |
| 视觉 | 刻意复刻 IDM | 保留工作流，视觉现代、克制、品牌化 |
| 启动 | 较快 | 目标 < 300ms 出窗口 |
| 内存 | 较低 | 目标空闲 < 80MB |
| 设置 | 12 页平铺 | 分组 + 搜索，常用项前置 |
| 语言 | 86 种 | 先 en / zh-CN，架构支持扩展 |
| 扩展 | 浏览器扩展 + native messaging | v1.0 本地 API + 深链；v1.1 扩展 |
| 种子/视频 | 全内置 | v1.2 起按模块推进 |
| 许可 | GPL-3.0 | MIT，独立实现 |

### 2.3 目标用户

1. **从 IDM 迁移的用户**：要同样的“多连接 + 续传 + 浏览器接管”，但不想付费/破解。
2. **开发者/运维**：要 CLI、JSON API、可脚本化、可跑在 NAS。
3. **注重隐私的用户**：不要账号、不要遥测、不要云。
4. **跨平台用户**：Mac/Linux 上也要一个像样的原生下载器。

## 3. 设计原则

1. **原生优先**：窗口、菜单、托盘、文件对话框、通知都用系统能力；不套 WebView。
2. **一屏完成**：下载列表、分类、队列、详情在同一窗口；不逼用户开多个窗口。
3. **状态可见**：每个下载的进度、速度、剩余时间、连接数、错误原因都能一眼看到。
4. **默认可信**：默认不限速、不接管剪贴板以外的内容、不监听公网、不上传数据。
5. **快**：启动快、滚动快、10 万行列表不卡、进度更新不闪烁。
6. **可脚本化**：UI 能做到的，CLI/API 也能做到。
7. **可扩展**：核心下载与 UI 解耦；种子、视频、浏览器、AI 都是模块。

| 宽度 | 布局 |
|---|---|
| ≥ 1120 | 侧边栏 236 + 六列（含 Added） |

| ≥ 820 | 侧边栏常驻；Add URL 显示文字 |
| < 820 | 侧边栏收起，标题行变成筛选菜单；Add URL 收成图标 |

| < 620 | 只剩 Name / Progress；隐藏搜索框与远程状态 |

### 4.7 语言

- 三种语言：English、简体中文、繁體中文；默认跟随系统。
- 语言在设置里随时切换，立即生效；菜单、托盘、远程页一起换。
- 日期、时间、数字、复数按 CLDR 规则；中文用“11月7日”“2 分 51 秒”，英文用“Nov 7”“2m 51s”。
- 技术性错误（HTTP 状态码、磁盘错误）保留英文原文。

### 4.6 动效

- 进度条宽度 300–400ms 缓动；数字不做跳动动画。
- 弹窗 120–160ms 淡入/缩放；遵循系统“减少动态”设置。
- 列表滚动原生惯性；不做花哨视差。
- 完成时状态点变绿 + 通知；不播放全屏动画。

## 6. 关键用户流程

### 6.1 第一次启动

1. 读取系统语言，默认中文/英文。
2. 选择下载目录（默认 `~/Downloads/downmygo`）。
3. 展示空状态：品牌标记 + “粘贴链接” + “从浏览器接管（即将支持）”。
4. 托盘图标出现；关闭窗口默认最小化到托盘并继续下载。

### 6.2 添加下载

```
Cmd/Ctrl+N 或点击 Add URL
   → 粘贴/输入链接
   → 自动预检（大小、文件名、是否可续传、是否重复）
   → 自动选择分类与目录
   → 可改文件名/目录/分类/连接数
   → 高级：Referer/Cookie/UA/校验和/描述
   → Start download / Download later
```

- 预检失败：显示原因（404/403/429/证书/超时），仍允许“仍然尝试”。
- 重复链接：按设置询问/编号/覆盖/复用。
- 文件已存在：自动编号，绝不覆盖非自己创建的文件。

### 6.3 下载中

- 表格行实时更新进度、速度、状态。
- 选中行 → 底部详情卡：URL、进度、大小、已下载、速度、剩余、连接数、分段图、暂停/删除。
- 双击未完成 → 展开详情；双击已完成 → 打开文件。
- 托盘菜单：暂停全部/继续全部/显示窗口/退出。
- 完成：通知 + 状态变绿 + 可选音效。

### 6.4 队列与定时

- 默认主队列运行，4 个并行。
- 添加时可选“稍后下载”进入主队列。
- 队列页：并行数、启动/停止、时间、每周几、一次性、完成后动作。
- 到点自动启动；到点停止；完成后按设置关机/睡眠/退出。

### 6.5 远程

- 设置里打开“允许局域网设备控制”，端口 8463。
- 手机打开 `http://<电脑IP>:8463`，首次输入设置里的 API token；也可用 `?token=` 直接打开。
- 可添加链接、查看进度、暂停/继续/删除、启动/停止队列。
- 默认只监听 `127.0.0.1`；打开远程后才监听私有地址。

### 6.6 CLI

```sh
downmygo get https://example.com/file.zip -o ~/Downloads -c 8
downmygo get https://example.com/file.zip --checksum sha256:...
downmygo https://example.com/file.zip
```

- 进度写 stderr，最终路径写 stdout，便于脚本。
- 退出码：0 成功，1 失败，2 用法错误。

### 6.7 API

```sh
curl -H "Authorization: Bearer $TOKEN" http://127.0.0.1:8463/api/downloads
curl -X POST -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
     -d '{"url":"https://example.com/a.zip"}' http://127.0.0.1:8463/api/add
```

## 10. 成功标准
