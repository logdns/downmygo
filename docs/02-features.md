# 功能与状态

每一项都写清楚：做到什么程度、怎么工作、边界在哪。图例：**✅ 完成** · **◐ 部分** · **○ 未做**。

## 1. 下载

| 功能 | 状态 | 说明 |
|---|---|---|
| 多连接 | ✅ | 1–32，默认 8；剩余最大段动态二分 |
| 断点续传 | ✅ | 分段表原子保存，最多丢 2 秒；崩溃/断网/重启后继续 |
| 预检 | ✅ | 大小、文件名、Range、ETag、Last-Modified |
| 单流回退 | ✅ | 服务器不支持 Range 时自动单连接并在界面标注 |
| 校验与文件时间 | ✅ | 可选 SHA-256；可选按 `Last-Modified` 设置文件时间 |
| 重试 | ✅ | 4xx 不重试；5xx/429/断流重试，退避上限 8 秒 |
| 停滞检测 | ✅ | 90 秒无数据关闭连接并重试 |
| 代理 / 绑定地址 | ✅ | system、socks5、http；本地地址绑定（VPN 断网保护） |
| 限速 | ✅ | 单下载 + 全局令牌桶；每 N 小时 M MB 的窗口 |
| 列表 | ✅ | 六列可排序、搜索、筛选、右键菜单、详情卡 |
| 分类 | ✅ | 7 个内置分类按扩展名归类，可增删改 |

## 6. 程序逻辑

### 启动

```
参数是 get/URL？→ CLI 跑完退出
读 state.json → 恢复列表（上次没下完的标记为暂停）
按设置或系统语言显示 → 建窗口、菜单、托盘 → 开 API（可选）→ 剪贴板监听
→ 命令行/深链带来的链接 → 启动时检查更新（可选）
```

### 一次下载

```
添加 → 是种子？→ torrent 客户端
     → 是视频/图库站？→ yt-dlp / gallery-dl（必要时先安装）
     → 是 debrid 站点？→ 换直链后走 HTTP
     → 否则 → HTTP 引擎（预检 → 分段 → 续传 → 校验 → 完成）
完成 → 自动解压（可选）→ 通知
```

### 状态机

```
Queued → Connecting → Downloading → Complete → Seeding（种子且开启做种）
   │          │             │
   ├→ Waiting（队列/调度/限额）  ├→ Error（可继续）
   └→ Paused（用户暂停/重启恢复）
```

`Waiting` 是程序在等条件，条件满足自动继续；`Paused` 是用户让停的。

### 调度与限速

- 队列：并行数、开始/停止时间、一次性日期、开机启动、完成后睡眠/休眠/关机/退出
- 限速：令牌桶取全局与单下载的较小者；流量窗口滚动后自动放行

## 7. 语言

- 文案在 `locales/*.json`（ARB + ICU），`en.json` 是源语言
- `go tool mygo generate` 生成带类型的访问器，生成文件要提交
- 界面、菜单、托盘、通知、远程页、API 状态、日期数字复数都跟随语言
- 内置分类/队列按语言显示；用户自建的名字原样
- CLI 与技术错误（HTTP 状态码、磁盘错误）保留英文

## 8. 明确不做

账号与云同步、广告与捆绑、破解或绕过付费服务、内置浏览器、移动端原生 App（远程页足够）。
