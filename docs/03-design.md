# 设计

## 1. 品牌

**downmygo** = down + my + go：我的下载，随走随用。

- 名字、包名、域名：`downmygo`、`app.downmygo.desktop`、`downmygo://`、`magnet:`
- 语气：平静、直接、可执行；错误说「发生了什么 + 下一步」，不写「极速」「秒杀」

### 标志

- 圆角方块（squircle），135° 渐变 `#4A78FF → #0FA79A`，左上高光、右下压暗
- 中央白色下载箭头，落在一根进度条上：箭头说「在下载」，进度条说「下了多少」
- 几何用有符号距离场画，任意尺寸都平滑；托盘是同一几何的单色模板图，系统自动反色
- 源文件是 Icon Composer 文档 `resources/downmygo.icon`；`go run ./tools/makeicon` 画图层、调 `ictool` 导出、按 macOS 网格留边（1024 画布、824 图形）

- 主题文件可覆盖以上 19 个角色与圆角/间距

## 3. 字体与间距

- 字号：10（标签）、11（次要）、12（正文）、13（列表）、15（详情标题）、17–18（标题）、20（关于）
- 间距基准 4，常用 6/8/10/12/14/16/20
- 圆角：控件 9–10，卡片 10–14，图标块 7–20

## 4. 布局

```
┌──────────────────────────────────────────────────────────────┐
│ 工具栏：品牌 · 添加链接 · 继续/暂停/移除/文件夹 · 任务 · 搜索 · 设置 │
├──────────────┬───────────────────────────────────────────────┤
│ 侧边栏 236   │ 标题行：当前筛选 · 数量 · 排序 · 详情            │
│              ├───────────────────────────────────────────────┤
│ 下载          │ 表格：名称 / 大小 / 进度 / 速度 / 状态 / 时间     │
│ 分类          │                                               │
│ 队列          ├───────────────────────────────────────────────┤
│              │ 详情卡（可折叠，默认 208）                       │
├──────────────┴───────────────────────────────────────────────┤
│ 状态栏：总速度 · 进行中 · 限速 · 远程 · 版本                    │
└──────────────────────────────────────────────────────────────┘
```

- 默认窗口 1120×720，最小 820×520；侧边栏与详情卡可拖拽，尺寸记忆
- 自适应：

| 宽度 | 布局 |
|---|---|
| ≥ 1120 | 六列（含添加时间） |
| ≥ 880 | 显示速度列 |
| < 820 | 侧边栏收起，标题行变筛选菜单；添加链接收成图标 |
| < 700 | 隐藏状态列与文件夹按钮 |
| < 620 | 只剩名称/进度；隐藏搜索与远程状态 |

- 对话框宽度取 `min(设计宽度, 窗口宽 - 32)`，窄窗口不溢出

## 5. 组件

| 组件 | 用法 |
|---|---|
| 工具栏 | 高 44–48；左品牌 + 主操作，右搜索 + 设置 |
| 图标按钮 | 点击区 24–30，图标 17，必须有 tooltip |
| 列表行 | 状态点 + 类型图标 + 名称/副标题；选中用强调色 |
| 进度 | 轨道 6px 圆角，填充强调色；完成显示对勾 |
| 空状态 | 品牌标记 64 + 标题 + 一句说明 + 主操作 |
| 详情卡 | 名称、地址、进度、六个统计、分段可视化、操作按钮 |
| 状态栏 | 高 30，次要信息，宽度不足时按优先级隐藏 |

## 6. 语言

- English、简体中文、繁體中文；默认跟随系统
- 切换立即生效，菜单、托盘、远程页一起换
- 日期、时间、数字、复数按 CLDR：`11月7日` / `Nov 7`，`2 分 51 秒` / `2m 51s`
- 技术错误保留英文原文，便于检索

## 7. 动效与反馈

- 只用于状态变化（进度、悬停、浮层），不做装饰动画
- 操作结果用 toast：复制链接、解压完成、导入数量、更新就绪
- 危险操作（删除文件）默认二次确认，可在设置里关
